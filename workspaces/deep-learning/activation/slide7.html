07 / 全面对比
激活函数横向对比
函数 值域 零中心 梯度消失 计算速度 可导性 典型应用
Sigmoid (0, 1) 否 严重 慢 平滑 二分类输出层
Tanh (−1, +1) 是 中等 慢 平滑 RNN / LSTM
ReLU [0, +∞) 否 正区间无 极快 x=0 不可导 CNN 默认选择
Leaky ReLU (−∞, +∞) 否 基本无 极快 x=0 不可导 替代 ReLU
ELU (−α, +∞) 近似 无 中等 平滑 深层 CNN
GELU ≈(−0.17, +∞) 近似 无 中等 平滑 Transformer / ViT
Swish ≈(−0.28, +∞) 近似 无 中等 平滑 EfficientNet / LLM

没有"万能"的激活函数 —— 选择取决于任务类型、网络架构和性能需求。 但趋势很清晰：从简单分段（ReLU）走向平滑非单调（GELU/Swish）。
