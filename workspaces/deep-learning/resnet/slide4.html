04 / 数学表达
残差学习的数学本质
y = F(x, {Wi}) + x
x：输入（恒等映射）   F(x)：残差函数（要学习的部分）   y：输出

如果最优映射接近恒等

理想情况：H(x) ≈ x

F(x) = H(x) − x ≈ 0

网络只需将权重推向零即可——优化器非常擅长这个任务。

如果最优映射需要学习

网络仍然有能力学习复杂的 F(x)

F(x) = H(x) − x ≠ 0

残差块有两层卷积，足够表达复杂的非线性变换。不会损失任何表达能力。

维度不匹配时

当通道数或尺寸变化时：

y = F(x, {Wi}) + Ws · x

通过 ×1 卷积（Ws）投影 x 到匹配维度，再做加法。
