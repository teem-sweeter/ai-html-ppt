模块 3

深度学习入门

神经网络基本结构

  • 神经元：接收输入，加权求和，激活输出
  • 层：多个神经元组成一层
  • 网络：多层堆叠形成网络
  • 输入层 → 隐藏层 → 输出层

前向传播

数据从输入层流向输出层的过程

z = W·x + b
a = σ(z)

每一层的输出是下一层的输入

反向传播

误差从输出层反向传播，计算梯度

损失 → 梯度 → 更新权重

链式法则：∂L/∂W = ∂L/∂a · ∂a/∂z · ∂z/∂W

常用激活函数

  • ReLU：max(0, x)，简单高效
  • Sigmoid：输出(0,1)，用于二分类
  • Softmax：多分类输出

激活函数引入非线性，让网络能拟合复杂函数

损失函数

  • MSE：均方误差，用于回归
  • CrossEntropy：交叉熵，用于分类

衡量预测值与真实值的差距

优化器

  • SGD：随机梯度下降
  • Adam：自适应学习率

根据梯度更新权重，最小化损失

模块 1

视觉 Transformer

标准 Transformer

Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V
  • Self-Attention：自注意力机制
  • Multi-Head：多头并行注意力
  • Position Encoding：位置编码
  • FFN：前馈网络

ViT (Vision Transformer)

  • Patch Embedding：图像切块
  • [CLS] Token：分类标识
  • 缺乏CNN的归纳偏置
  • 需要大规模数据预训练

DeiT：引入蒸馏机制

Swin Transformer

  • Window Attention：局部窗口注意力
  • Shifted Window：移动窗口
  • 层次化特征构建
  • 线性计算复杂度 O(n)

CV任务的通用骨干网络

ConvNeXt

  • 用现代技巧反向优化ResNet
  • 大卷积核 (7×7)
  • GELU激活、LayerNorm
  • 复刻ViT性能

证明CNN仍有生命力
