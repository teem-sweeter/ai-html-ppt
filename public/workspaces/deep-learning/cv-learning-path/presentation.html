模块 3

深度学习入门

神经网络基本结构

  • 神经元：接收输入，加权求和，激活输出
  • 层：多个神经元组成一层
  • 网络：多层堆叠形成网络
  • 输入层 → 隐藏层 → 输出层

前向传播

数据从输入层流向输出层的过程

z = W·x + b
a = σ(z)

每一层的输出是下一层的输入

反向传播

误差从输出层反向传播，计算梯度

损失 → 梯度 → 更新权重

链式法则：∂L/∂W = ∂L/∂a · ∂a/∂z · ∂z/∂W

常用激活函数

  • ReLU：max(0, x)，简单高效
  • Sigmoid：输出(0,1)，用于二分类
  • Softmax：多分类输出

激活函数引入非线性，让网络能拟合复杂函数

损失函数

  • MSE：均方误差，用于回归
  • CrossEntropy：交叉熵，用于分类

衡量预测值与真实值的差距

优化器

  • SGD：随机梯度下降
  • Adam：自适应学习率

根据梯度更新权重，最小化损失
