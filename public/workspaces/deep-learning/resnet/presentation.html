01 / 问题背景
更深的网络，反而更差？

直觉上，更深的神经网络应该能学习更复杂的特征，表现更好。但实验发现， 当网络层数增加到一定程度后，训练误差反而上升了—— 这不是过拟合（测试误差也在上升），而是训练本身变得更困难。

TRAINING ERROR vs NETWORK DEPTH

退化问题

网络越深，训练误差反而越高。

  • 不是过拟合
  • 不是梯度消失
  • 优化本身变得更难

核心疑问

如果新增的层什么都不做（恒等映射），深层网络至少不应比浅层差。为什么实际做不到？

02 / 核心思想
如果学习恒等映射很难，
那就让它变得容易

ResNet 的核心洞察：与其让网络直接学习目标映射 H(x)，不如让它学习残差 F(x) = H(x) − x。这样，如果最优解就是恒等映射，网络只需把 F(x) 学成 0 即可—— 比学习 H(x) = x 容易得多。

传统网络

直接学习目标映射 H(x)

x → [层] → H(x)

如果最优解是恒等映射，需要把权重学成恰好使得 H(x) = x，这很难精确优化。

残差网络 (ResNet)

学习残差 F(x) = H(x) − x

x → [层] → F(x) + x

如果最优解是恒等映射，只需 F(x) → 0，把权重推向 0 即可——这是优化器擅长的。

04 / 数学表达
残差学习的数学本质
y = F(x, {Wi}) + x
x：输入（恒等映射）   F(x)：残差函数（要学习的部分）   y：输出

如果最优映射接近恒等

理想情况：H(x) ≈ x

F(x) = H(x) − x ≈ 0

网络只需将权重推向零即可——优化器非常擅长这个任务。

如果最优映射需要学习

网络仍然有能力学习复杂的 F(x)

F(x) = H(x) − x ≠ 0

残差块有两层卷积，足够表达复杂的非线性变换。不会损失任何表达能力。

维度不匹配时

当通道数或尺寸变化时：

y = F(x, {Wi}) + Ws · x

通过 ×1 卷积（Ws）投影 x 到匹配维度，再做加法。

05 / 两种残差块
Basic Block vs Bottleneck Block

Basic Block

用于 ResNet-18 / ResNet-34

Bottleneck Block

用于 ResNet-50 / 101 / 152

为什么 Bottleneck 更高效？

Bottleneck 先用 1×1 卷积降维（如 256→64），再用 3×3 卷积处理， 最后用 1×1 卷积升维回（64→256）。这样 3×3 卷积在低维空间进行，计算量大幅减少， 同时保持了表达能力。

07 / 为什么有效
梯度的高速公路

残差连接为梯度反向传播提供了一条"捷径"，让梯度可以直接从深层传回浅层， 有效缓解梯度消失问题。

没有残差连接

梯度必须逐层相乘才能传回浅层：

∂L/∂x = ∂L/∂y · ∂h₁/∂x · ∂h₂/∂h₁ · ... · ∂y/∂hn

每一项 < 1 时，连乘 → 0（梯度消失）
每一项 > 1 时，连乘 → ∞（梯度爆炸）

有残差连接

梯度有了直接通路：

∂L/∂x = ∂L/∂y · (∂F/∂x + 1)

那个 +1 是关键！即使 ∂F/∂x 很小， 梯度仍然 ≥ 1，不会消失。

残差连接让网络深度从 ~20层 突破到 1000+ 层仍然能有效训练，
是深度学习历史上最重要的架构创新之一。

09 / 总结
ResNet 带来了什么？
F

残差学习

学习 F(x) = H(x) − x，而非直接学 H(x)。让恒等映射变得容易学习，解决退化问题。

+

跳跃连接

shortcut connection 直接传递输入，梯度有了"高速公路"，训练数百层成为可能。

D

突破深度极限

从此前约 20 层的上限，一举推进到 152 层甚至更深，同时训练误差持续下降。

★

深远影响

残差连接已成为现代网络的标配组件，影响了 Transformer、DenseNet 等后续架构的设计哲学。

y = F(x) + x
一个简单优雅的加法，彻底改变了深度学习的历史进程。
