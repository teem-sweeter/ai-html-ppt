01 / 核心概念
什么是激活函数？为什么需要它？

激活函数是神经网络中每个神经元的"开关"——它接收输入的加权求和，经过一个非线性函数变换后输出。 没有它，无论网络多少层，最终都只是一个线性变换。

神经元的运作

输入 → 加权求和 → 激活函数 → 输出

z = w₁x₁ + w₂x₂ + b
a = σ(z)

直觉理解

就像大脑神经元：只有当输入信号足够强（超过某个阈值）时，神经元才会"激活"并向下传递信号。

为什么不能没有激活函数？

02 / 经典激活函数
Sigmoid — 最早的激活函数
σ(x) = 1 / (1 + e−x)
σ(x) = 1 / (1 + e−x)
导数: σ'(x) = σ(x) · (1 − σ(x))

优点

  • 输出 (0,1)，可表示概率
  • 处处可导，平滑连续
  • 历史经典，易于理解

缺点

  • 梯度消失：两端梯度接近0
  • 输出非零中心，影响收敛
  • 含 exp 运算，计算较慢

梯度消失示意

当 x 很大或很小时，σ'(x) ≈ 0。反向传播时梯度经过连乘会趋近于零， 深层网络的前几层几乎无法更新。

03 / 经典激活函数
Tanh — 零中心的改进
tanh(x) = (ex − e−x) / (ex + e−x)
tanh(x)
导数: tanh'(x) = 1 − tanh²(x)
本质上是 Sigmoid 的缩放平移版本

优点 vs Sigmoid

  • 零中心输出 (−1, +1)
  • 梯度更强（最大值 1 vs 0.25）
  • 收敛速度更快

仍然存在的问题

  • 两端仍有梯度消失
  • 仍含 exp 运算，计算开销
  • 深层网络效果仍不理想

与 Sigmoid 的关系

tanh(x) = 2σ(2x) − 1
tanh 是 sigmoid 的线性变换版本，值域从 (0,1) 变为 (−1,+1)

04 / 现代标准
ReLU — 深度学习的默认选择
ReLU(x) = max(0, x)
f(x) = max(0, x)
导数: x > 0 时为 1，x < 0 时为 0
计算极其简单，无需指数运算

优点

  • 计算极快：只需比较大小
  • 正区间梯度恒为 1，不消失
  • 稀疏激活，提升效率
  • 收敛速度远超 Sigmoid/Tanh

缺点

  • Dead ReLU：负区间梯度为 0
  • 神经元可能永久"死亡"
  • 输出非零中心

Dead ReLU 问题

当输入持续为负时，梯度永远为 0，权重不再更新。 这个神经元就"死"了。学习率过大时更容易发生。

05 / ReLU 变体
解决 Dead ReLU 的三种方案

Leaky ReLU

f(x) = max(αx, x)，α = 0.01

负区间给一个很小的斜率（通常 0.01），保证梯度不为零，神经元不会"死亡"。

PReLU

f(x) = max(αx, x)，α 可学习

与 Leaky ReLU 类似，但 α 是通过训练自动学习的参数，而非固定值。

ELU

f(x) = x (x > 0)，α(ex − 1) (x ≤ 0)

负区间用指数函数平滑过渡，输出均值更接近零，有助于收敛。但计算稍慢。

06 / 现代激活函数
GELU & Swish — Transformer 时代的宠儿

GELU

GELU(x) = x · Φ(x)

其中 Φ(x) 是标准正态分布的累积分布函数。 直觉：输入越大，被保留的概率越高。

使用场景：BERT、GPT、ViT 等 Transformer 架构的标配

Swish / SiLU

Swish(x) = x · σ(x)

其中 σ 是 Sigmoid 函数。自门控机制：输入本身决定激活程度。

使用场景：EfficientNet、LLaMA、Mistral 等现代模型

关键洞察：GELU 和 Swish 都是平滑、非单调的——它们在负区间有一个微小的"下凹"， 这让模型能对负输入也保留微弱的梯度信号，同时起到隐式正则化的效果。这正是它们在大模型中表现优异的原因之一。

07 / 全面对比
激活函数横向对比
函数 值域 零中心 梯度消失 计算速度 可导性 典型应用

Tanh (−1, +1) 是 中等 慢 平滑 RNN / LSTM

没有"万能"的激活函数 —— 选择取决于任务类型、网络架构和性能需求。 但趋势很清晰：从简单分段（ReLU）走向平滑非单调（GELU/Swish）。

08 / 实践指南
如何选择激活函数？

CNN 图像任务

ReLU 仍然是安全的默认选择。
追求更好效果时试 Swish。

Transformer / NLP

GELU 是标准选择（BERT、GPT 系列均使用）。

输出层

二分类 → Sigmoid
多分类 → Softmax
回归 → 无激活 / 线性

遇到 Dead ReLU

换用 Leaky ReLU 或 ELU，或降低学习率。

09 / 总结
激活函数的演进之路
σ

非线性是核心

没有激活函数，神经网络就是线性变换的堆叠，表达能力极其有限。激活函数赋予了网络拟合任意复杂函数的能力。

∇

梯度是关键约束

激活函数的选择直接影响梯度流。Sigmoid/Tanh 的梯度消失催生了 ReLU，ReLU 的 Dead 问题催生了变体。

~

从分段到平滑

演进方向是：分段线性（ReLU）→ 平滑非单调（GELU/Swish）。平滑性让优化更稳定，非单调性带来隐式正则化。

⚡

实用建议

CNN 默认 ReLU，Transformer 用 GELU，大模型用 Swish，输出层按任务选择。没有万能解，根据场景决定。

Sigmoid → Tanh → ReLU → Leaky ReLU → GELU → Swish

每一代都在解决上一代的核心缺陷，推动深度学习不断突破边界
