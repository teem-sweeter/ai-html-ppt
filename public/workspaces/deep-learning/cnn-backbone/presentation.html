02 / 开山之作

LeNet-5 (1998)

网络结构图

历史意义

第一个成功的CNN架构，证明了卷积神经网络在图像识别任务上的有效性，为后续所有CNN架构奠定了基础。

局限性

网络较浅，只能处理简单任务（手写数字识别），无法处理复杂图像。

03 / 深度学习复兴

AlexNet (2012)

网络结构图

关键突破

  • ReLU替代Sigmoid，加速训练
  • Dropout正则化技术
  • GPU训练的先驱
  • 数据增强技术

历史意义

在ImageNet竞赛中大幅领先传统方法，开启了深度学习时代，证明了深层网络+大数据+GPU的强大组合。

04 / 小卷积核哲学

VGGNet (2014)

核心思想

用多个3×3小卷积核堆叠替代大卷积核，增加网络深度同时减少参数。

两个3×3卷积的感受野 = 一个5×5卷积

网络变体

  • VGG-11：11层
  • VGG-13：13层
  • VGG-16：16层
  • VGG-19：19层

设计原则

  • 统一使用3×3卷积核
  • 统一使用2×2最大池化
  • 通道数逐层翻倍：64→128→256→512
  • 结构规整，易于实现

影响

证明了网络深度对性能的重要性，3×3小卷积核成为后续CNN的标准配置。

05 / 多尺度特征

GoogLeNet / Inception (2014)

Inception模块

并行使用不同大小的卷积核，提取多尺度特征后拼接。

  • 1×1卷积
  • 3×3卷积
  • 5×5卷积
  • 3×3最大池化

核心创新

  • 1×1卷积：降维，减少计算量
  • 多尺度并行特征提取
  • 全局平均池化替代全连接
  • 22层深度，仅500万参数

1×1卷积的作用

在3×3和5×5卷积前使用1×1卷积降维，大幅减少计算量，同时增加非线性。

历史意义

证明了网络宽度和深度同样重要，Inception模块成为经典设计模式。

06 / 残差学习

ResNet (2015)

残差块结构图

核心创新

  • 残差连接：学习残差而非映射
  • 恒等映射：梯度高速公路
  • 解决深层网络退化问题
  • 可训练100+层网络

历史意义

ResNet是CNN历史上最重要的突破之一，残差连接成为现代深度学习的标配，影响了Transformer等后续架构。

07 / 特征复用

DenseNet (2017)

核心思想

每一层都与前面所有层直接连接，极致的特征复用。

xₗ = Hₗ([x₀, x₁, ..., xₗ₋₁])

Dense Block

  • 每一层接收所有前面层的输出
  • 特征图在通道维度拼接
  • 增长率(growth rate)控制新增通道数
  • 参数效率极高

优势

  • 特征复用：减少冗余
  • 梯度流畅通
  • 参数效率高
  • 一定的正则化效果

与ResNet对比

ResNet是相加（add），DenseNet是拼接（concat）。DenseNet特征复用更彻底，但显存占用更大。

08 / 轻量化网络

MobileNet 系列

深度可分离卷积 vs 标准卷积

MobileNet V2

  • 倒残差结构：先升维再降维
  • Linear Bottleneck：去除ReLU
  • 残差连接在低维空间
  • 更适合移动端

MobileNet V3

  • SE模块：通道注意力
  • NAS搜索网络结构
  • h-swish激活函数
  • 性能与效率的最佳平衡
09 / 复合缩放

EfficientNet (2019)

核心思想

同时平衡网络的深度、宽度和分辨率三个维度。

复合缩放

depth: d = α^φ
width: w = β^φ
resolution: r = γ^φ

EfficientNet-B0

  • NAS搜索基础网络
  • MBConv模块（倒残差）
  • SE注意力模块
  • Swish激活函数

性能表现

EfficientNet-B7在ImageNet上达到84.3% Top-1，同时比当时最优模型小8.4倍、快6.3倍。
